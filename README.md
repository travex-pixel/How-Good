# How Good?

Experiments in building games with Claude Code.

## 🎮 [SCRAPBOUND: LOOT RIOT](scrapbound/)

A chaotic auto-battler in a fantasy junkyard: 8 fighters, a Magnetic Scrap Storm, loot that changes how you fight, and bosses. Plays on phone and desktop.

**Play locally:** open `scrapbound/index.html` in a browser. Full details, controls, tests and GitHub Pages instructions are in [`scrapbound/README.md`](scrapbound/README.md).

![Scrapbound on a phone](scrapbound/docs/battle-phone.png)

## 🐍 [Snake](snake/)

A small first demo showing how Claude Code writes, tests and checks a game in a real browser.
